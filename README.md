# a7672s-connect
Simcom A7672S 4G LTE + GNSS + BLE module MQTT interface for micro controllers and embedded processors

## Running MQTT Example

```sh
# get ritJson run the example code 
git submodule update --init

cd example/mqtt/

mkdir build
cd build

cmake ..

make

./a7672sConnect_mqtt
```
